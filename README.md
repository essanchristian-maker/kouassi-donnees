# Données publiques KOUASSI PRONOSTIC

Pronostics de football calculés par le moteur KOUASSI PRONOSTIC et republiés automatiquement plusieurs fois par
jour. Ce dépôt ne contient que des données publiques (pronostics, fiabilité, bilan) : aucun code, aucune clé,
aucune donnée personnelle. Les pronostics sont des probabilités, pas des certitudes. Réservé aux plus de 18 ans.
